## 📌 Project Overview

This project is an end-to-end **DevOps implementation of a Java-based Pet Adoption Application**, deployed on a scalable cloud infrastructure using modern automation, CI/CD, and configuration management practices.

The system demonstrates a full **cloud-native deployment pipeline** with automated infrastructure provisioning, continuous integration and delivery, security scanning, and dynamic host configuration.

## Project Objectives

- Deploy a Java-based web application on AWS cloud infrastructure  
- Implement Infrastructure as Code for automated provisioning  
- Build a complete CI/CD pipeline using Jenkins  
- Enable dynamic host discovery and configuration using Ansible  
- Integrate security, monitoring, and artifact management tools 

## Cloud Architecture

- Cloud Provider: Amazon Web Services (AWS)  
- Compute: EC2 Instances (Auto Scaling Group)  
- Infrastructure Automation: Terraform  
- Configuration Management: Ansible (Auto-Discovery Enabled)  


##  CI/CD Pipeline

- CI/CD Tool: Jenkins  
- Source Control: GitHub  
- Build Tool: Maven  
- Artifact Repository: Nexus Repository  
- Containerisation: Docker  

Pipeline Flow:

GitHub → Jenkins → Build → Test → Security Scan → Artifact Storage → Deployment

## Key DevOps Feature: Dynamic Host Discovery

A major feature of this project is the **Ansible Auto-Discovery mechanism**, which:

- Detects newly provisioned EC2 instances automatically  
- Updates Ansible inventory with private IPs  
- Ensures seamless configuration and deployment  
- Supports scalability without manual intervention
